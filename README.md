\# ShopSphere



ShopSphere is an e-commerce backend built with Java and Spring Boot.



\## Technology Stack



\- Java 25

\- Spring Boot

\- Maven

\- MySQL

\- Spring Security

\- Git



\## Planned Services



\- Auth Service

\- User Service

\- Product Service

\- Cart Service

\- Order Service

\- Payment Service



\## Development Status



Project foundation in progress.
